# 🎴 自定义抽卡

一个高度可定制的 AstrBot 抽卡插件：自定义唤醒词、文件夹式多卡池（每群可独立分配）、AI 视觉模型自动生成卡牌名称与图鉴文案、每日限抽、图鉴收集进度、日/月/总排行榜，并自带多页面 WebUI 管理面板与管理员私聊调试会话。

> 📝 本插件由 AI 编写。

> 支持平台：`aiocqhttp`(`qq`) / `discord` / `telegram`

## 功能特性

- 🧩 **完全自定义触发词**：抽卡、图鉴、排行榜、帮助、调试会话的触发词均可配置，带不带斜杠 `/` 均可。
- 🗂️ **文件夹式多卡池**：图片来源按文件夹归类；可为每个群单独分配一个卡池文件夹，多个群可共用同一文件夹。
- 🖼️ **AI 卡牌分析**：接入 AstrBot 官方对话模型，自动为导入的图片生成 3-8 字卡牌名与风趣图鉴文案（可在配置中关闭）。
- 📥 **图鉴与收集进度**：一键查看你的抽卡档案，显示「已收集 X / 卡池总 Y 种」以及金色收集进度条，按抽取次数排序。
- 🏆 **排行榜**：日榜 / 月榜 / 总榜，按「群内」分别统计每个成员抽到的卡片次数，生成排行图片。
- ⏱️ **每日限抽**：可配置每个用户每天最大抽卡次数（默认 1，填 0 不限）。
- 🛠️ **管理员调试会话**：超级管理员私聊进入调试菜单，切换任意卡池测试抽卡（结果不计入记录）、为某群分配卡池，全程菜单式对话。
- 🖥️ **WebUI 管理面板**：多页面后台（总览 / 图片 / AI 分析 / 卡池 / 抽卡历史），支持图片导入、文件夹管理、批量分析可视化进度、按群查看与删除用户记录。

## 安装方法

### 方法一：WebUI 上传 zip（推荐）

1. 下载本仓库的 Release 压缩包（`astrbot_plugin_custom_gacha.zip`，内含插件目录）。
2. 打开 AstrBot 管理面板 → **插件** → **安装插件** → 选择 **上传 ZIP 安装**，选择该压缩包。
3. 安装完成后在插件列表启用**自定义抽卡**。

### 方法二：手动放置

将 `astrbot_plugin_custom_gacha` 整个文件夹放入 AstrBot 的 `data/plugins/` 目录，然后重启 AstrBot。

> 每张导入的卡片图片会生成对应的 `cards/*.png` 卡面预览；若更换过字体或修改了代码，需**重启 AstrBot 容器/进程**才能生效（插件模块有缓存）。

## 快速开始

安装并启用后，默认已有一个名为 **「饭饭表情包」** 的卡池文件夹。请先准备图片：

1. 在 **WebUI → 图片** 页面上传图片（支持 `jpg/png/gif`，可批量或打包上传），也可新建文件夹归类。
2. （可选）在 WebUI → **AI 分析** 页面配置视觉模型后批量分析，生成卡牌名与图鉴文案。
3. 在群里发送默认唤醒词「**抽卡**」即可随机抽一张卡。

## 配置项详解

所有配置项均可在 **AstrBot 插件配置页**编辑，说明如下：

| 配置键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `trigger_words` | list | `["抽卡"]` | 抽卡唤醒词，带不带斜杠均可 |
| `allow_direct_trigger` | bool | `true` | 开启后直接发送唤醒词即触发；关闭则仅响应 `/唤醒词` |
| `match_mode` | string | `exact` | `exact` 整句完全一致触发；`starts_with` 以唤醒词开头触发 |
| `history_trigger_words` | list | `["图鉴","我的图鉴","抽卡图鉴"]` | 图鉴直达唤醒词 |
| `daily_limit_count` | int | `1` | 每个用户每天最大抽卡次数，`0` 表示不限 |
| `board_daily_word` | string | `抽卡日榜` | 日榜触发词 |
| `board_monthly_word` | string | `抽卡月榜` | 月榜触发词 |
| `board_total_word` | string | `抽卡总榜` | 总榜触发词 |
| `help_trigger_words` | list | `["帮助","菜单","抽卡帮助"]` | 帮助菜单触发词（输出内容按当前配置动态生成） |
| `debug_trigger_word` | string | `自定义抽卡调试` | 管理员私聊调试会话触发词 |
| `super_users` | list | `[]` | 抽卡调试超级管理员列表；留空则使用 AstrBot 配置的超级管理员 |
| `vision_model_provider` | string | `""` | AI 分析视觉模型（`Provider`），从官方模型列表选择；留空则不自动分析 |
| `vision_model` | string | `""` | 模型名称覆盖，一般留空使用所选 Provider 的默认模型 |
| `analysis_temperature` | float | `0.8` | AI 分析温度，越低越稳定、越高越有梗 |
| `analysis_max_tokens` | int | `512` | AI 分析单图返回最大 token |
| `analysis_system_prompt` | string | 内置 | 图鉴总编 System Prompt，用于控制卡牌名/文案风格，保持默认即可 |
| `analysis_prompt_template` | string | `""` | 覆盖每张图片的提问模板，可用 `{filename}` / `{name}`，留空用内置 |

## 卡池与多群分配

卡池采用**文件夹**组织：所有图片按 `images/<文件夹名>/` 存放，默认文件夹为 **「饭饭表情包」**。

- **每群独立卡池**：可为指定群分配一个文件夹，该群抽卡只从该文件夹取图；未绑定的群使用默认文件夹。
- **多群共享**：多个群可以指定同一个文件夹。
- **WebUI 管理**：`群卡池` 页面支持新建文件夹、绑定「群号 → 文件夹」、把勾选的图片批量移动到其它文件夹。
- **调试设置**：也可以在管理员调试会话中为某群分配卡池（见下文）。

---

## 排行榜

排行榜按**群内**口径统计每个人抽到卡片的总次数，生成一张排行图片，包含名次、头衔卡牌与抽取次数。

- 日榜 / 月榜 / 总榜分别独立累计，数据按群隔离。
- 触发词为自定义的 `抽卡日榜` / `抽卡月榜` / `抽卡总榜`。
- 在所有平台上排行图均以图片形式发送。

---

## 每日限抽

默认每个用户每天最多抽卡 **1** 次（可在 `daily_limit_count` 修改，写 `0` 表示不限）。

达到上限后再发送抽卡，机器人会提示你今天已抽过卡，并**重新发送一张「今日抽卡」汇总图**，列出你今天抽到的所有卡片。

## AI 卡牌分析

开启 AI 分析后，每张导入的图片会自动（或通过 WebUI 触发）调用视觉模型生成卡牌信息：

- **卡牌名**：3-8 个字，一语道破天机、风趣有画面感。
- **图鉴文案**：40-120 字单段，带网络梗、风趣和一点哲学意味。

在 **WebUI → AI 分析** 页面可查看批量分析进度（含中断恢复、停止按钮）。所有已分析的文案保存在 `manifest.json` 中，重启不丢失。

## WebUI 管理面板

通过 AstrBot 插件的 WebUI 入口打开，包含以下页面：

| 页面 | 功能 |
| --- | --- |
| 总览 | 统计卡池图片数、已分析数、抽卡人数等 |
| 图片 | 上传 / 删除图片，按文件夹筛选，批量移动到其它文件夹 |
| AI 分析 | 配置模型后批量分析，带实时进度、停止按钮、中断恢复 |
| 群卡池 | 新建文件夹、绑定「群 → 文件夹」、批量移动图片 |
| 抽卡历史 | 按群分类展示各用户抽卡次数/种类/最常抽中；点击「查看图鉴」查看该用户档案图，「删除记录」删除其抽卡记录 |

> 说明：WebUI 运行在 AstrBot 的沙箱 iframe 中，删除操作采用**两段式按钮确认**（再点一次才真正删除），不依赖浏览器弹窗。
>
> 若页面改动后遇到异常，请强制刷新（`Ctrl+F5`）以加载最新脚本。

## 管理员调试会话

用于抽卡前的卡池调试与配置，**所有测试抽卡均不计入排行榜与用户记录**。

**进入方式**：在 `super_users` 中配置的超级管理员（留空则使用 AstrBot 全局超级管理员）**私聊**发送「`自定义抽卡调试`」（触发词可改）。

随后出现调试菜单：

```
🎴 抽卡调试菜单（仅私聊）
当前调试卡池：饭饭表情包（N 张）
1️⃣ 切换调试卡池
2️⃣ 设置某群的卡池（群号 + 文件夹）
3️⃣ 测试抽卡（不计入记录）
4️⃣ 查看卡池配置
0️⃣ 退出
回复数字即可继续。
```

继续对话即可按菜单操作：

- **1 / 切换卡池** → 列出所有文件夹，输入文件夹名切换当前调试卡池。
- **2 / 设置某群卡池** → 输入 `群号 文件夹名`（如 `123456 饭饭表情包`）为该群分配卡池。
- **3 / 测试抽卡** → 使用当前调试卡池抽一张卡，**不计入**任何记录与排行。
- **4 / 查看配置** → 展示默认卡池、各文件夹及群的绑定关系。
- **0 / 退出** → 结束会话。

> 安全说明：调试会话只会在超级管理员的**私聊**中生效，且必须先用触发词开启；打断会话或回复无关内容不会误触发二级菜单，反之普通群聊中的「抽卡」等关键词也绝不影响调试会话。

## 数据存储结构

插件数据保存在 AstrBot 的插件数据目录下（`data/plugin_data/astrbot_plugin_custom_gacha/`）：

```
├── images/            # 卡池图片（按文件夹分组存放）
├── cards/             # 每张卡生成的卡面预览图
├── manifest.json      # 图片清单（文件名、卡池名、AI 文案等）
├── history.json       # 每个用户的抽卡历史
├── boards.json        # 排行榜数据（日/月/总，按群隔离）
└── settings.json      # 插件设置（触发词、每日限抽、群卡池绑定等）
```

> 删除图片/记录会同步清理对应数据；排行榜数据随抽卡实时写入，删除用户记录会一并清除其榜单数据。

## 常见问题

**Q1：改了配置或代码后不生效 / 图片文字变成方框 □？**
AstrBot 对插件 Python 模块有缓存，修改 `main.py` 或更换字体后需**重启 AstrBot 容器/进程**。若渲染中文出现方框，请确保容器内安装了中文字体，或将字体文件放入插件资源目录。

**Q2：怎么让 AI 自动分析？**
在配置里选择 `vision_model_provider`（官方模型下拉选一个支持图片输入的对话模型），并在 WebUI → AI 分析 触发批量分析即可。

**Q3：排行榜没数据？**
排行榜只统计**群内抽卡**，私聊调试抽卡（`record=False`）不计入。

**Q4：同一人在多个群抽卡，历史会混在一起吗？**
不会。WebUI 抽卡历史按 `群 → 用户` 分类展示，各群数据独立。旧记录若无群号会归入「私聊 / 未分组」。
